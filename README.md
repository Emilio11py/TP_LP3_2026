# Sistema CAE

Trabajo práctico de Lenguaje de Programación 3.

El proyecto tiene un backend en Go y una aplicación web en Angular. Estamos avanzando en su desarrollo por etapas.

## Cómo ejecutar

Se necesitan Go, Node.js y npm.

En una terminal, inicia el backend:

```powershell
cd backend
go run .\cmd\api
```

En otra terminal, inicia el frontend:

```powershell
cd frontend
npm install
npm start
```

Abre <http://localhost:4200> en el navegador.
